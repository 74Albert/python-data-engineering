# Data Engineering ETL Pipelines (Apache Airflow)

Репозиторий с практическими проектами по построению ETL-пайплайнов, оркестрации задач и работе с базами данных.

## Стек технологий

- **Язык:** Python (Pandas, SQLAlchemy, Requests)
- **Оркестрация:** Apache Airflow
- **Базы данных:** PostgreSQL
- **Инфраструктура:** Docker, Docker Compose

## Реализованные пайплайны (DAGs)

В папке `dags/` находятся три пайплайна, демонстрирующие различные подходы к работе с данными:

### 1. Сбор курсов валют (`allratestoday_api_dag.py`)

**Задача:** Автоматический сбор данных о курсах USD, EUR и CNY к RUB.

**Логика:** Пайплайн обращается к внешнему API (AllRatesToday), извлекает данные в формате JSON, преобразует их в DataFrame и загружает в базу данных PostgreSQL.

**Особенности:** Настроен на регулярный запуск (каждые 10 минут). Реализована обработка ошибок API и логирование.

### 2. Загрузка данных Titanic (`titanic_dag.py`)

**Задача:** Классический ETL-процесс.

**Логика:** Чтение локального CSV-файла, фильтрация нужных колонок, переименование полей под стандарты БД и загрузка в PostgreSQL.

**Особенности:** Демонстрирует базовую работу с Pandas внутри Airflow и настройку подключения к базе данных через переменные окружения.

### 3. Обмен данными между задачами (`titanic_xcom_dag.py`)

**Задача:** Демонстрация работы с XCom (Cross-Communication) в Airflow.

**Логика:** Первая задача (Extract) читает данные и возвращает количество строк. Вторая задача (Load) забирает это число из XCom и записывает результат в лог-таблицу базы данных.

**Особенности:** Показывает, как задачи могут передавать друг другу метаданные и как организовать логирование этапов пайплайна.

## Как запустить проект локально

1. Убедитесь, что у вас установлен Docker Desktop.
2. Клонируйте репозиторий:

```bash
git clone https://github.com/74Albert/python-data-engineering.git
cd python-data-engineering
```

3. Запустите контейнеры Airflow:

```bash
docker compose up -d
```

4. Откройте веб-интерфейс Airflow по адресу: http://localhost:8080
   Логин: airflow
   Пароль: airflow
(Обратите внимание: для работы пайплайнов требуется настроенный файл .env с доступами к БД, который не включен в репозиторий по соображениям безопасности).
